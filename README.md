# Toy Defense Calculator

![Toy Defense Calculator Favicon](favicon.png)

## Features

- **Lunchbox Calculator**: Calculate exact item yields, optimal toolbox purchases, and total toy output based on your current Crackers budget.
- **Items Browser**: Browse all 102 items with filtering by Category (Soldiers, Traps, Blocks), Rarity, and multi-field sorting by DPS, Health, Damage, Range, Name, or Drop Rate.
- **Wave Calculator**: Calculate exact wave earnings per run, per minute, and per hour powered by the game's exact Luau wave scaling formula.
- **Boost & Pass Toggles**: Toggle +50% Toys Gamepass, +50% Crackers Gamepass, +10% Roblox Group Bonus, and +15% Roblox Premium Bonus with persistent LocalStorage settings.
